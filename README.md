- **Framework**: React 19 + Vite 6
- **Styling**: Tailwind CSS v4 (Tropical Brutalist Luxury Palette)
- **3D Graphics**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Animation Choreography**: GSAP + ScrollTrigger, Motion
- **Smooth Scroll**: Lenis

## ?? Getting Started

```bash
# Clone the repository
git clone https://github.com/iriewebstudios/irie-web-studios.git

# Navigate into the project folder
cd "Irie Web Studios"

# Install dependencies
npm install

# Start development server
npm run dev
```

Build for production:

```bash
npm run build
```
